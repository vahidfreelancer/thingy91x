This folder contains precompiled binaries and DFU images for the Thingy:53 compatible samples and applications in the nRF Connect SDK. 

The sample folder may contain up-to three files:

+-----------------------------------+-------------------------------------------------+---------------------------------------------------------------------+
|              File                 |                   Description                   |                     How to program to Thingy:53                     |
+-----------------------------------+-------------------------------------------------+---------------------------------------------------------------------+
| merged_CPUAPP.hex                 | Application core binary                         | Using an external debug probe and nRF Connect Programmer            |
| merged_CPUNET.hex                 | Network core binary                             | Using an external debug probe and nRF Connect Programmer            |
| dfu_application_<sample_name>.zip | MCUboot compatible update images for both cores | Using nRF Programmer for Android and iOS, or nRF Connect Programmer |
+-----------------------------------+-------------------------------------------------+---------------------------------------------------------------------+

Note: Some samples have both a release configuration and debug configuration, denoted by Release and Debug in the file names.
